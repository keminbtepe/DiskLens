## ✨ Özellikler

- ⚡ **Paralel tarama:** Disk ve klasörleri birden fazla iş parçacığıyla tarar.
- 🌳 **Klasör ağacı:** Klasörleri ihtiyaç duydukça genişleterek incelemenizi sağlar.
- 📊 **Alan kullanımı:** Disk doluluk çubuğu ve klasör boyutu göstergeleri sunar.
- 🔍 **Boyut filtresi:** Tüm dosyaları veya 1 MB, 10 MB, 100 MB, 500 MB, 1 GB ve 5 GB üzerindeki dosyaları filtreleyin.
- 🎚️ **Tarama modları:** Dengeli, Çok hızlı ve Maksimum (SSD) seçenekleri.
- ⏸️ **Tarama kontrolü:** Tarama işlemini duraklatın, devam ettirin veya iptal edin.
- 👀 **Canlı durum:** Taranan konumu ve son taranan öğeleri takip edin.
- 🌓 **Tema seçimi:** Açık ve koyu görünüm arasında geçiş yapın.
- 🗂️ **Dosya yönetimi:** Seçilen dosya veya klasörün konumunu açın, yeniden adlandırın, taşıyın veya silin.
- ♻️ **Geri Dönüşüm Kutusu:** Silme işlemi, Windows'un desteklediği durumlarda öğeleri Geri Dönüşüm Kutusu'na gönderir.
- ⚠️ **Uyarılar ve koruma:** Gizli/sistem öğeleri ve korunan sistem konumları için uyarılar ve kısıtlamalar bulunur.

## 🚀 Hızlı başlangıç

### 1. ⬇️ Projeyi indirin

Bu GitHub sayfasının üst kısmındaki **Code → Download ZIP** yolunu izleyin.

### 2. 📦 ZIP dosyasını çıkarın

İndirdiğiniz ZIP dosyasına sağ tıklayın ve **Tümünü Ayıkla** seçeneğini kullanın.

### 3. ▶️ Uygulamayı başlatın

Çıkardığınız klasörde aşağıdaki dosyalardan birine çift tıklayın:

- **Önerilen:** `BASLAT_DiskLens.bat`
- Alternatif: `DiskLensPremiumV3.cmd`

### 4. 🔎 Taramaya başlayın

Uygulamada bir disk veya klasör seçin ve **Hızlı tara** düğmesine basın.

<a id="tr-kullanim"></a>

## 🖱️ Nasıl kullanılır?

1. **📁 Konum seçin:** Bir disk ya da belirli bir klasör seçin.
2. **🎯 Dosya boyutunu belirleyin:** İsterseniz yalnızca belirli boyutun üzerindeki dosyaları listeleyin.
3. **⚙️ Tarama modunu seçin:** Dengeli, Çok hızlı veya Maksimum (SSD) modlarından birini kullanın.
4. **🧩 Tarama kapsamını ayarlayın:** Alt klasörleri ve sistem/gizli öğeleri dahil etme seçeneklerini kontrol edin.
5. **🚀 Taramayı başlatın:** Sonuçları klasör ağacında inceleyin; büyük öğeleri kolayca fark edin.
6. **⏯️ Gerekirse kontrol edin:** Tarama sırasında duraklatma, devam ettirme veya iptal seçeneklerini kullanın.

### Dosya ve klasör işlemleri

Bir öğeyi seçtiğinizde kullanılabilir işlemler arasından seçim yapabilirsiniz:

- 📂 Konumunu aç
- ✏️ Yeniden adlandır
- 📦 Taşı
- 🗑️ Sil

> ⚠️ **Silmeden önce mutlaka kontrol edin:** Öğenin tam yolunu ve ne işe yaradığını inceleyin. Önemli sistem veya kişisel dosyaları silmeyin.

# 🇬🇧 English

DiskLens Premium is a portable disk-usage analyzer for Windows. It helps you find which files and folders are using your storage, inspect folder sizes, and manage selected items from one interface.

> 💡 **No installer required.** Extract the ZIP package and run a launcher.

<a id="en-features"></a>

## ✨ Features

- ⚡ **Parallel scanning:** Scans disks and folders using multiple workers.
- 🌳 **Folder tree:** Expand folders on demand to explore their contents.
- 📊 **Storage overview:** Disk usage bar and folder-size indicators.
- 🔍 **File-size filter:** Show all files or filter files above 1 MB, 10 MB, 100 MB, 500 MB, 1 GB or 5 GB.
- 🎚️ **Scan modes:** Balanced, Very Fast and Maximum (SSD).
- ⏸️ **Scan controls:** Pause, resume or cancel a scan.
- 👀 **Live status:** Follow the current scan location and recently scanned items.
- 🌓 **Themes:** Switch between light and dark appearance.
- 🗂️ **File management:** Open the selected item's location, rename, move or delete it.
- ♻️ **Recycle Bin:** Where supported by Windows, deleted items are sent to the Recycle Bin.
- ⚠️ **Warnings and protection:** Warnings for hidden/system items and restrictions for protected system locations.

<a id="en-quick-start"></a>

## 🚀 Quick start

### 1. ⬇️ Download the project

On this GitHub page, select **Code → Download ZIP**.

### 2. 📦 Extract the ZIP file

Right-click the downloaded ZIP and choose **Extract All**.

### 3. ▶️ Launch the app

In the extracted folder, double-click one of these files:

- **Recommended:** `BASLAT_DiskLens.bat`
- Alternative: `DiskLensPremiumV3.cmd`

### 4. 🔎 Start scanning

Choose a disk or folder in the app and click **Hızlı tara** (Quick scan).

<a id="en-usage"></a>

## 🖱️ How to use

1. **📁 Choose a location:** Select a disk or a specific folder.
2. **🎯 Set a file-size filter:** Optionally list only files above a selected size.
3. **⚙️ Choose a scan mode:** Balanced, Very Fast or Maximum (SSD).
4. **🧩 Set the scan scope:** Choose whether to include subfolders and hidden/system items.
5. **🚀 Start scanning:** Explore the results in the folder tree and identify large items.
6. **⏯️ Control the scan:** Pause, resume or cancel while scanning.

### File and folder actions

After selecting an item, you can use the available actions:

- 📂 Open its location
- ✏️ Rename
- 📦 Move
- 🗑️ Delete

> ⚠️ **Review before deleting:** Check the full path and purpose of an item. Do not delete important system or personal files.

<a id="en-requirements"></a>

## 💻 Requirements

| Requirement | Details |
|---|---|
| Operating system | Windows 10 or Windows 11 |
| PowerShell | Windows PowerShell 5.1 |
| UI framework | WPF |

ℹ️ **Technical note:** DiskLens is not a compiled standalone `.exe`. It runs with PowerShell and WPF, which are available on supported Windows desktop installations.

<a id="en-safety"></a>

## 🛡️ Safety and privacy

- DiskLens scans file-system information in the disks and folders you select.
- File operations such as delete or move are initiated by the user and require confirmation.
- Where supported by Windows, deletion sends items to the Recycle Bin.
- A hidden/system warning does not mean that an item is safe to delete.
- Keep regular backups of important data.
- The application may create local diagnostic logs on your computer.

### 🧾 Diagnostic logs

The following files may be created during troubleshooting:

- `DiskLens_Hata.log`
- `DiskLens_Baslatma.log`
- `DiskLens_Debug.log`

These logs may contain personal information such as file paths or user-folder names. **Review them before sharing publicly.** They are excluded from version control by `.gitignore`.

<a id="en-troubleshooting"></a>

## 🧰 Troubleshooting

If the application does not start or reports an error:

1. Make sure you extracted the entire ZIP package.
2. Run `DiskLensPremiumV3_Debug.cmd`.
3. Review the error message in the PowerShell window.
4. Before sharing diagnostic logs, remove personal paths and other private information.
